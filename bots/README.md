# bots/

Collection of small chaos bots for the Repository of Randomness.

| Bot | Command | Purpose |
|-----|---------|--------|
| `melonking_bot.py` | `python bots/melonking_bot.py` | Royal decrees, status, plague reports |
| `scooter_bot.py` | `python bots/scooter_bot.py` | Free-time enforcement & scooter dispatches |
| `nonsense_bot.py` | `python bots/nonsense_bot.py` | Confident useless statements |
| `node_infection_bot.py` | `python bots/node_infection_bot.py` | Fake infection snapshot |

All bots are safe, local, and opinionated. Run any of them whenever order threatens to return.
